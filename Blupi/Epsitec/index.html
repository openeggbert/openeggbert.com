Epsitec

Epsitec
Github https://github.com/epsitec-sa
Website https://epsitec.ch
Epsitec is a Swiss company, which developed Speedy Blupi I and Speedy Blupi II.
Epsitec was never a game company.
Speedy Blupi III was never created. The reason may be, that the game development was not profitable for Epsitec.
Epsitec now develops software for small businesses.
