Directory Structure

Image or IMAGE08 directory

This directory contain images with 8 bit depth.
  • Image format: BMP
  • File name extension: BLP
Additionally Open Eggbert also supports:
  • BMP images with the BMP file extension.
  • PNG images with the PNG file extension.

IMAGE16 directory

This directory contain images with 16 bit depth.
  • Image format: BMP
  • File name extension: BLP
Additionally Open Eggbert also supports:
  • BMP image format with the BMP file extension.
  • PNG image format with the PNG file extension.

SOUND directory

This directory contain music and sound files.
  • Music format: MIDI with file name extension BLP
  • Sound format: WAV with file name extension BLP
Additionally Open Eggbert also supports:
  • MIDI music format with the MID file extension.
  • MP3 music format with the MP3 file extension.
  • OGG music format with the OGG file extension.
  • WAV music format with the WAV file extension.
  • MP3 sound format with the MP3 file extension.
  • OGG sound format with the OGG file extension.
  • WAV sound format with the WAV file extension.
