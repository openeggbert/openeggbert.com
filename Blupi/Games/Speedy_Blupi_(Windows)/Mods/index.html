Mods

Modding "Speedy Blupi" means one or more of the following actions:

  • sound (WAV or MIDI) files in the installation directory are modified
  • graphics (BMP) files in the installation directory are modified (with an art program like Gimp)
  • levels (BLP) files are modified. Sometimes all the levels are replaced by the new ones (main hub, world hubs, words). The cheatplayer provides to possibility to replace the already existing levels with newer levels.
  • EXE file is modified (disassembling / EXE file hexadecimal editing)

Speedy Blupi 2 - remastered by Jesse Savoie

Some of the changes:

  • All sprite sheets are now evenly spaced, simplifying the creation of texture mods.
  • Most textures have been updated to 16-bit color, assuming your computer can handle it (unless you're still using Windows 95 or a similar old system).
  • BMP, MID, WAV, and XCH files are correctly named, with only a few BLP files remaining in the data folder.
  • Dream blocks no longer change into kids blocks in SB2.
  • Music tracks #1 and #7 have been fixed to remove the long silence at the end.
  • Various visual glitches and animation errors have been corrected.
  • Use F7 for x4 speed and F8 for x8 speed.
  • The windowed resolution has been changed to 640x480 from the previous 640x477.
  • The CD requirement has been removed (offset was changed: 4f6(for SB1) or 506 (for SB2) from 75 to eb)

Opinions may vary on what should be fixed and what should remain unchanged (for instance, the unavoidable bomb in SB1’s mechanic level 2).
Few another things could be improved too.

  • Images ends with ".bmp", not ".blp".
  • Sounds ends with ".wav", not ".blp".
  • Music files ends with ".midi", not ".blp".
