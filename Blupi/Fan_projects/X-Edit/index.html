X-Edit

X-Edit is another level editor for the Speedy Blupi / Speedy Eggbert series of computer games.
Author: Messerschmitt262a2a (Youtube channel: Youtube channel)
X-Edit is closed source application, its source code is not available.
It was probably developed between 2017 and 2018. It is not known, if it is now still actively developed (but privately).
As it is closed source, it does not exist on Github.
Used programming language is probably C#.

Investigation

It was almost not yet done any further investigation.
X-Edit needs this to be installed (maybe also some other libraries are needed):

  • Microsoft XNA Framework Redistributable 4.0 (which means to install file xnafx40_redist.msi)

X-Edit runs on Linux via Wine, but xnafx40_redist.msi may be needed to be installed.
