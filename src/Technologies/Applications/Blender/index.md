Free 3D modeling tool.

## Usage

### Objects

| Action | How to |
| --- | --- |
| Rendering | menu / Render / Render Image or F12 |
| Move | menu or G |
| Rotate | menu or R |
| Scale | menu or S |
| Duplicate | Shift + D |
| Delete | X or Delete |
| Precise movement | Shift (hold) |
| Incremental movement | Ctrl (hold) |
| Hide | H |
| Unhide All | Alt + H |
| Add object | Shift + A |

### Change view

Orbit (rotate) - middle mouse button

<br>

Zooming - wheel mouse button

<br>

Panning (move view) - Shift and middle mouse button
