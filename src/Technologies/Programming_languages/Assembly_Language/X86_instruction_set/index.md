This article targets the [i586](Technologies/Programming_languages/Assembly_Language/I586/index.html) instruction set (Pentium 100).

- i586 is needed for the [decompilation](Technologies/Other/Reverse_engineering/index.html) of the [EXE](Technologies/Platforms/Windows/EXE/index.html) files of the [Speedy Blupi](Blupi/Games/Speedy_Blupi_(Windows)/index.html) [game](Article_does_not_yet_exist_or_link_is_broken/index.html) for [Windows](Technologies/Platforms/Windows/index.html).
