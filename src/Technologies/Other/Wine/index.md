Wine is a compatibility layer providing the possibility to run many Windows apps/games on Linux.

### Boxedwine

Boxedwine is an [emulator](Article_does_not_yet_exist_or_link_is_broken/index.html) that allows [Windows](Technologies/Platforms/Windows/index.html) applications to run. It accomplishes this by using an unmodified [32-bit](Article_does_not_yet_exist_or_link_is_broken/index.html) version of [Wine](Article_does_not_yet_exist_or_link_is_broken/index.html), while emulating the [Linux](Technologies/Platforms/Linux/index.html) kernel and [CPU](Article_does_not_yet_exist_or_link_is_broken/index.html). It is written in [C++](Technologies/Programming_languages/C++/index.html) with [SDL](Article_does_not_yet_exist_or_link_is_broken/index.html) and is supported on multiple platforms. <br> Boxedwine runs in browser too. [Speedy Eggbert](Blupi/Games/Speedy_Eggbert/index.html) runs in Boxedwine in [browser](Article_does_not_yet_exist_or_link_is_broken/index.html), but is too slow and buggy.
