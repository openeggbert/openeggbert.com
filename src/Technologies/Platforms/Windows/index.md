Windows is the proprietary operating system developed by

[Microsoft](Article_does_not_yet_exist_or_link_is_broken/index.html)

.

## Relation to Speedy Blupi

Speedy Blupi for

[Desktop](Article_does_not_yet_exist_or_link_is_broken/index.html)

can run on

[Windows 95](Technologies/Platforms/Windows/Windows_95/index.html)

or the newer versions of the Windows operating system.

<br>

Speedy Blupi can even run on Windows 11, the newest version of the operating system at this moment (2024-11-09).

- But [Direct Play](Article_does_not_yet_exist_or_link_is_broken/index.html), the deprecated [DirectX](Technologies/Libraries/DirectX/index.html) component, must be installed additionally.
