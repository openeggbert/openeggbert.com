**X-Edit** is another [level editor](Article_does_not_yet_exist_or_link_is_broken/index.html) for the [Speedy Blupi](Article_does_not_yet_exist_or_link_is_broken/index.html) / [Speedy Eggbert](Article_does_not_yet_exist_or_link_is_broken/index.html) series of [computer](Article_does_not_yet_exist_or_link_is_broken/index.html) [games](Article_does_not_yet_exist_or_link_is_broken/index.html). <br> Author: Messerschmitt262a2a (Youtube channel: [Youtube channel](https://www.youtube.com/@Messerschmitt262a2a)) <br> **X-Edit** is [closed source](Article_does_not_yet_exist_or_link_is_broken/index.html) [application](Article_does_not_yet_exist_or_link_is_broken/index.html), its [source code](Article_does_not_yet_exist_or_link_is_broken/index.html) is not available. <br> It was probably developed between 2017 and 2018. It is not known, if it is now still actively developed (but privately). <br> As it is closed source, it does not exist on Github. <br> Used programming language is probably [C#](Article_does_not_yet_exist_or_link_is_broken/index.html). <br>

## Investigation

It was almost not yet done any further investigation. <br> X-Edit needs this to be installed (maybe also some other libraries are needed): <br>

- Microsoft XNA Framework Redistributable 4.0 (which means to install file xnafx40_redist.msi)

X-Edit runs on Linux via Wine, but xnafx40_redist.msi may be needed to be installed.
