[Speedy Blupi](Blupi/Games/Speedy_Blupi_(Windows)/index.html)

(Data Games) is a game for the

[Windows Phone](Article_does_not_yet_exist_or_link_is_broken/index.html)

platform developed for the

[Windows Phone](Article_does_not_yet_exist_or_link_is_broken/index.html)

platform and officially released in

[2013](Article_does_not_yet_exist_or_link_is_broken/index.html)

by game studio

[Dada Games](Blupi/Games/Speedy_Blupi_(Windows_Phone)/Dada_Games/index.html)

led by

[Daniel Roux](Blupi/Community/Daniel_Roux/index.html)

. This game was developed by Daniel Roux in its spare time.

<br>

This Windows Phone release was simply titled "Speedy Blupi", although it was based on

[Speedy Blupi II](Article_does_not_yet_exist_or_link_is_broken/index.html)

. it also contains updated levels and new features added ''after'' SB2. It was probably created rewriting Speedy Blupi II from C++ to C# and from DirectX 3.0 to XNA 4.0, then new features were added.

<br>

Development of

[Speedy Blupi](Blupi/Games/Speedy_Blupi_(Windows)/index.html)

for

[Windows Phone](Article_does_not_yet_exist_or_link_is_broken/index.html)

is discontinued by

[Daniel Roux](Blupi/Community/Daniel_Roux/index.html)

.

<br>

[XAP](Article_does_not_yet_exist_or_link_is_broken/index.html)

file of Speedy Blupi targets Windows Phone 7.5 version, which means, that:

- [Visual Studio](Article_does_not_yet_exist_or_link_is_broken/index.html) 2010 or 2012 were probably used to developed Speedy Blupi for Windows Phone. Or [XNA Game Studio](Article_does_not_yet_exist_or_link_is_broken/index.html) could be also used for the development.
- [.NET Compact Framework](Article_does_not_yet_exist_or_link_is_broken/index.html) 4.0 was used for the development.

Speedy Blupi for Windows Phone is closed-source and its original source code is not available.

<br>

It seems, that Speedy Blupi for Windows Phone has almost no new features, if compared to Speedy Blupi I and Speedy Blupi II.

<br>

The graphics is almost the same, but there are some differences. Riding the jeep or jetpack provides some new animations in the game,

[Blupi](Blupi/index.html)

/

[Eggbert](Article_does_not_yet_exist_or_link_is_broken/index.html)

is moving down or up.

<br>

**How to play**

## Porting to modern devices

In November

[2024](Article_does_not_yet_exist_or_link_is_broken/index.html)

Speedy Blupi for Windows Phone (XAP files) was successfully decompiled by

[Robert Vokac](Blupi/Community/Robert_Vokac/index.html)

and the

[ILSpy](Article_does_not_yet_exist_or_link_is_broken/index.html)

[decompiler](Article_does_not_yet_exist_or_link_is_broken/index.html)

was used. This game was originally developed for only for the Windows Phone platform, but now it runs on Windows,

[Linux](Technologies/Platforms/Linux/index.html)

,

[Android](Article_does_not_yet_exist_or_link_is_broken/index.html)

and in

[web browser](Article_does_not_yet_exist_or_link_is_broken/index.html)

too. It may runs on

[MacOS](Article_does_not_yet_exist_or_link_is_broken/index.html)

too.

<br>

As of November 2024 the game started on Android, but scaling and touch controls were not working correctly and if the Play button was pressed, the game crashed.

<br>

As of December 2024 the game runs on Android, touch control is working, but the graphics still needs some fixes.

<br>

On 26th December 2024 the game was ported to the web browser using the

[KNI](Article_does_not_yet_exist_or_link_is_broken/index.html)

game framework (fork of

[MonoGame](Article_does_not_yet_exist_or_link_is_broken/index.html)

)

## Comparison to Speedy Blupi II

Speedy Blupi(Dada Games) is a significantly simplified and easier version of Speedy Blupi II.

<br>

Eggs are everywhere, but many features are missing. There's no supercharger, springs, personal bombs, and invisibility and shield are combined into one item. Players can't fire glue or ride a tank.

<br>

Although these features still function in the phone version, they are excluded from the levels to simplify the controls.

<br>

Cheats are in this version for Windows Phone presented too.

<br>

It seems, that images for Blupi animations, blocks are the same as in Speedy Blupi II.

## How to install on Windows Phone 8 or 8.1 - physical device

Windows Store for Windows Phone platform was killed by Microsoft in

[2019](Article_does_not_yet_exist_or_link_is_broken/index.html)

.

- This means: since 2019 you cannot install Speedy Blupi using the Windows Store.

Installing XAP files directly on Windows Phone 8 or 8.1 devices is not possible. ''This is a restriction was decided and implemented by the Microsoft company.''

<br>

There is an alternative way, how to install Speedy Blupi (or other applications) on Windows Phone 8 or 8.1 devices (even now in 2024). You need to:

1. Unlock the bootloader (using the [WPInternals](Article_does_not_yet_exist_or_link_is_broken/index.html) application)
2. Enable the root access (using the WPInternals application)
3. Deploy the Speedy Blupi XAP file

**Warning:**

Please, note, that only some physical devices are supported by the WP Internal tool (only Nokia Lumia devices).

<br>

**Note:**

It was not yet investigated, if there is an alternative tool to the WP Internals application.

<br>

*Speedy Blupi was was successfully tested and running on the on Nokia Lumia 920, other devices were not yet tested.*

<br>

**Warning:**

unlocking the bootloader and rooting the physical device have some risks. Make backup of files on the Windows Phone device, if needed.

### Steps

**External link:**

[
        http://allaboutwindowsphone.com/features/item/24245_Aguideforunlockingthebootloade.php](http://allaboutwindowsphone.com/features/item/24245_Aguideforunlockingthebootloade.php)

1. Install [Windows Device Recovery Tool](Article_does_not_yet_exist_or_link_is_broken/index.html)
2. Install Windows Phone Internals (I have finally used a version released in 2015, the latest version did
                not work) https://github.com/ReneLergner/WPinternals
3. Install Windows Phone SDK 8.0 Lite and Windows Phone SDK 8.1 Lite
                [https://archive.org/details/wp-8.1-sdk-tools-lite-setup-av-1.20_202201](https://archive.org/details/wp-8.1-sdk-tools-lite-setup-av-1.20_202201)
4. Download files for your phone models (if exist). For Nokia Lumia: https://lumiafirmware.com
5. Run [Windows Phone Internals](Article_does_not_yet_exist_or_link_is_broken/index.html), unlock the bootloader,
                root the device using the downloaded files.
6. Then press the Windows logo key, type "Deploy" and start the [Windows Application Deployment 8.1](Article_does_not_yet_exist_or_link_is_broken/index.html) application and
                deploy the XAP file.

## How to install on Windows 10 Mobile - physical device

Open the Settings section of the Windows 10 Mobile physical devices and enable developer mode.

- Now you can deploy XAP files using the [Windows Application Deployment 8.1](Article_does_not_yet_exist_or_link_is_broken/index.html) application.

**Note:**

To install Speedy Blupi (the XAP file) on Windows 10 Mobile devices: It is not needed to unlock the bootloader and enable the root access

## How to install on Windows 10 Mobile - emulator

It is possible (successfully tested) to run Speedy Blupi on Windows 10 Pro or Windows 11 Pro.

- *Warning: The control of the game is difficult. The game does not support the control using the
                keyboard, only the touchscreen is supported.*
- *But you can enable (in the settings of the emulator) and use the multi-touch feature of the
                emulator.*

**Requirements:**

- Windows 10 Pro or 11 Pro
- 4 GB RAM or more

**Install:**

- Microsoft Emulator for Windows 10 Mobile Anniversary Update
- Microsoft Emulator via Microsoft Store
- Windows Phone SDK 8.0 Lite and Windows Phone SDK 8.1 Lite [https://archive.org/details/wp-8.1-sdk-tools-lite-setup-av-1.20_202201](https://archive.org/details/wp-8.1-sdk-tools-lite-setup-av-1.20_202201)

**Actions:**

- Start Microsoft Emulator and run any of the 6 emulated devices
- Run [Windows Application Deployment 8.1](Article_does_not_yet_exist_or_link_is_broken/index.html) and deploy the file speedblu.xap
- Now you can play Speedy Blupi for Windows Phone, but on Windows 10 or Windows 11.

*Note: There is a Windows Phone emulator for Android, but its development is no more active and it only supports several XAP applications, installation Speedy Blupi on this emulator was not successful.*

## Differences to Speedy Blupi (Windows)

### Level format

Level format is a txt format.

<br>

These levels were ported to the PC version (XCH format):

[https://drive.openeggbert.com/speedy_blupi/windows/mods/speedy_blupi_phone_levels_ported_to_pc/speedy_blupi_phone_levels_ported_to_pc.7z](https://drive.openeggbert.com/speedy_blupi/windows/mods/speedy_blupi_phone_levels_ported_to_pc/speedy_blupi_phone_levels_ported_to_pc.7z)

<br>

**Header:**

- **posDecor:** represents the initial camera position.
- **dimDecor:** specifies the level's width and height (the old game treats any value above 0 as 100).
- **world:** purpose is not yet known and needs investigation
- **region:** sets the background.

![](https://drive.openeggbert.com/Blupi/Games/Speedy_Blupi_(Windows_Phone)/Speedy_blupi_windows_phone_level_format.jpg)

### Graphics

Sprites are high-color with a full transparency.

<br>

All sprite sheets are a uniform square grid.  the block id's occupied by dream blocks are now decorative tiles

<br>

here's the main graphics file:

[https://drive.openeggbert.com/Blupi/Games/Speedy_Blupi_(Windows_Phone)/resources/speedy_blupi_windows_phone_icons.zip](https://drive.openeggbert.com/Blupi/Games/Speedy_Blupi_(Windows_Phone)/resources/speedy_blupi_windows_phone_icons.zip)

<br>

The screen ratio differs from the 4:3 aspect ratio used in the Speedy Blupi I/2 Windows releases. Instead, it matches the aspect ratio of the specific Windows Phone device, ensuring the game fills the screen properly without distorting the graphics.

### Behaviour

Some objects are respawned, if used.

<br>

Some mechanics is different than on the PC: Jump high is different (todo - specify the jump high)

### Controls

Keyboard is not supported in the original game released in 2013. Support for the keyboard was added, after the game was decompiled.

<br>

Supported controls are:

- White transparent buttons on the touch screen
- Accelerometer
