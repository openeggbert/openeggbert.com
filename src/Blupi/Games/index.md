Welcome to our comprehensive list of games featuring Blupi, also known as Speedy Eggbert. Created by Daniel
        Roux, these games span various genres including educational, puzzle, and strategy. This collection showcases the
        diversity and charm of Blupi games, highlighting the creativity and innovation behind each title.

<br>

For additional information and to explore a wider range of Blupi-related games, visit the Blupi Fandom Games
        Category

[https://blupi.fandom.com/wiki/Category:Games](https://blupi.fandom.com/wiki/Category:Games)

.

## Complete List of Blupi Games

- **Toto a la maison (1988)** - Early Blupi game featuring family-oriented content.
- **Toto s'amuse (1990)** - A game focused on entertainment and fun.
- **Toto Blupi at Home** - An educational game designed for learning.
- **[Toto a la campagne](Article_does_not_yet_exist_or_link_is_broken/index.html)** - Adventure game set in the
                countryside.
- **[Fun with Blupi](Article_does_not_yet_exist_or_link_is_broken/index.html)** - Interactive game with various
                mini-games.
- **[Blupi's Travels](Article_does_not_yet_exist_or_link_is_broken/index.html)** - A travel-themed game featuring
                Blupi.
- **[Toto apprend le vocabulaire](Article_does_not_yet_exist_or_link_is_broken/index.html)** - Vocabulary
                learning game.
- **[Blupi Explorer](Article_does_not_yet_exist_or_link_is_broken/index.html) (1993)** - Exploration game with
                educational elements.
- **[Blupimania](Article_does_not_yet_exist_or_link_is_broken/index.html) (1994)** - A challenging puzzle game.
- **[Planet Blupi](Blupi/Games/Planet_Blupi/index.html) (1997)** - Real-Time Strategy game
                set on a fictional planet.
- **[Speedy Blupi I](Article_does_not_yet_exist_or_link_is_broken/index.html) (1998)** - A popular platformer
                game.
- **[Speedy Eggbert 1](Article_does_not_yet_exist_or_link_is_broken/index.html)** - The first entry in the Speedy
                Eggbert series.
- **[Speedy Blupi II](Article_does_not_yet_exist_or_link_is_broken/index.html) (2001)** - Sequel to Speedy Blupi
                I.
- **[Speedy Eggbert 2](Article_does_not_yet_exist_or_link_is_broken/index.html)** - Follow-up to Speedy Eggbert
                1.
- **[CoLoBot](Article_does_not_yet_exist_or_link_is_broken/index.html) (2001)** - Educational game teaching
                programming basics.
- **[Ceebot](Article_does_not_yet_exist_or_link_is_broken/index.html) (2002)** - Programming-focused game.
- **[Buzzing Cars](Article_does_not_yet_exist_or_link_is_broken/index.html) (2002)** - Racing and driving game.
- **[Blupimania II](Article_does_not_yet_exist_or_link_is_broken/index.html) (2003)** - Second installment in the
                Blupimania puzzle series.
- **[Speedy Blupi for Windows Phone](Article_does_not_yet_exist_or_link_is_broken/index.html) (2013)** - Mobile
                adaptation of Speedy Blupi.
- **[Blupi is Back](Article_does_not_yet_exist_or_link_is_broken/index.html)** - Latest project reviving the
                Blupi character.
