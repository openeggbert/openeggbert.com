This is an Open Eggbert fork of the [Planet Blupi](Blupi/Games/Planet_Blupi/index.html) game by [Epsitec](Blupi/Epsitec/index.html). The original Planet Blupi game uses [Windows API](Technologies/Libraries/Windows_API/index.html) and [DirectX](Technologies/Libraries/DirectX/index.html) 3. This fork replaces those dependencies with Open Eggbert's own reimplementations: [Free API](Projects/Free_Api/index.html) (Windows API replacement) and [Free Direct](Projects/Free_Direct/index.html) (DirectX 3 replacement built on [CNA](Projects/CNA/index.html) and [SDL 3](Technologies/Libraries/SDL/index.html)).

This makes Planet Blupi runnable on [Linux](Technologies/Platforms/Linux/index.html), [MacOS](Technologies/Platforms/MacOS/index.html), [Android](Technologies/Platforms/Android/index.html) and Web without Wine or Windows.
