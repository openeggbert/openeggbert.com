## Welcome to Open Eggbert

**OpenEggbert.com** is a fan website dedicated to the game **Speedy Blupi**. It features an extensive archive of Speedy Blupi related content: **documentation**, **websites**, **files**, **GitHub repositories**, **YouTube videos**.

## Introduction

**[Speedy Blupi (Epsitec)](Article_does_not_yet_exist_or_link_is_broken/index.html)**: a [2D](Article_does_not_yet_exist_or_link_is_broken/index.html) [action](Article_does_not_yet_exist_or_link_is_broken/index.html) game released by the [Epsitec](Blupi/Epsitec/index.html) company in [1998](Article_does_not_yet_exist_or_link_is_broken/index.html) and [2001](Article_does_not_yet_exist_or_link_is_broken/index.html) for [Windows](Technologies/Platforms/Windows/index.html) platform (finished).

- Speedy Blupi I was released in [1998](Article_does_not_yet_exist_or_link_is_broken/index.html). Speedy Blupi II was released in [2001](Article_does_not_yet_exist_or_link_is_broken/index.html) and is the [sequel](Article_does_not_yet_exist_or_link_is_broken/index.html).

**[Speedy Blupi (Dada Games)](Article_does_not_yet_exist_or_link_is_broken/index.html):** a game created and released by [Daniel Roux](Blupi/Community/Daniel_Roux/index.html) in [2013](Article_does_not_yet_exist_or_link_is_broken/index.html) for the [Windows Phone](Article_does_not_yet_exist_or_link_is_broken/index.html) platform (finished) <br> **[Free Eggbert: ](Article_does_not_yet_exist_or_link_is_broken/index.html)** is the revival of [Speedy Blupi (Epsitec)](Article_does_not_yet_exist_or_link_is_broken/index.html) , that brings this game to life in a modern way using the Free Direct library.

- Multiple platforms will be supported: [Windows](Technologies/Platforms/Windows/index.html), [Linux](Technologies/Platforms/Linux/index.html), [MacOS](Article_does_not_yet_exist_or_link_is_broken/index.html), [Android](Article_does_not_yet_exist_or_link_is_broken/index.html), [Web](Article_does_not_yet_exist_or_link_is_broken/index.html) (via Emscripten)
- Used technologies: C++ (programming language), Free Direct (game library)
- Current status: To do
- Free Eggbert is based on the decompiled version of Speedy Eggbert II

**[Mobile Eggbert](Article_does_not_yet_exist_or_link_is_broken/index.html):** is the revival of [Speedy Blupi (Dada Games)](Article_does_not_yet_exist_or_link_is_broken/index.html).

- C# (programming language) version: The [XAP](Article_does_not_yet_exist_or_link_is_broken/index.html) executable file was decompiled. The [XNA](Article_does_not_yet_exist_or_link_is_broken/index.html) 4.0 game engine was replaced by its alternative implementations: [MonoGame](Article_does_not_yet_exist_or_link_is_broken/index.html), [FNA](Article_does_not_yet_exist_or_link_is_broken/index.html), [KNI Engine](Article_does_not_yet_exist_or_link_is_broken/index.html). Mobile Eggbert runs on several platforms: [Windows](Technologies/Platforms/Windows/index.html), [Linux](Technologies/Platforms/Linux/index.html), [Android](Article_does_not_yet_exist_or_link_is_broken/index.html), web browser. Status: finished (but issues exist)
- C++ (programming language) version: [Speedy Blupi (Dada Games)](Article_does_not_yet_exist_or_link_is_broken/index.html) is being rewritten from C# to C++. XNA 4.0 is being replaced by the CNA library. Status: In progress

**CNA:** XNA 4.0 like wrapper around the SDL 3 library<br> **Free Direct:** DirectX 3 like wrapper around the CNA library<br> **Free Api:** Reimplementation of Windows Api used by the Speedy Blupi (Epsitec) game.

## Future

1. Reverse engineering of [Speedy Blupi (Epsitec)](Article_does_not_yet_exist_or_link_is_broken/index.html) [EXE](Article_does_not_yet_exist_or_link_is_broken/index.html) files using the x86 instruction set and using tools like [Ghidra](Article_does_not_yet_exist_or_link_is_broken/index.html) and [IDA](Article_does_not_yet_exist_or_link_is_broken/index.html).
2. All [3D](Article_does_not_yet_exist_or_link_is_broken/index.html) models in Speedy Blupi will be recreated using [Blender](Article_does_not_yet_exist_or_link_is_broken/index.html).
3. The Speedy Blupi Windows version will feature new image assets rendered in Blender, with the game running at 60 [FPS](Article_does_not_yet_exist_or_link_is_broken/index.html), which requires three times more frames than the original, necessitating source code changes.
4. The [color depth](Article_does_not_yet_exist_or_link_is_broken/index.html) for the Speedy Blupi Windows version will be updated to 24-bit, phasing out 8-bit and 16-bit colour depth.
5. The block size for textures will be increased to 256x256 pixels, replacing the original 64x64 resolution.
6. All [WAV](Article_does_not_yet_exist_or_link_is_broken/index.html) sound files in Speedy Blupi will be recreated using Audacity or a similar tool, with some sounds recorded using a microphone. It’s possible that some sounds in the game include the voice of [Daniel Roux](Article_does_not_yet_exist_or_link_is_broken/index.html).
7. All [MIDI](Article_does_not_yet_exist_or_link_is_broken/index.html) music files in Speedy Blupi will be recreated using probably the application [Microsoft Music Producer](Article_does_not_yet_exist_or_link_is_broken/index.html)

## Name origin

The name "Open Eggbert" is not "Open Blupi", because "Blupi" is the registered trademark of [Epsitec](Blupi/Epsitec/index.html) company. ([link](https://branddb.wipo.int/en/quicksearch/brand/CH501993000002322?sort=score%20desc&start=0&rows=30&asStructure=%7B%22_id%22:%2253d3%22,%22boolean%22:%22AND%22,%22bricks%22:%5B%7B%22_id%22:%2253d4%22,%22key%22:%22brandName%22,%22value%22:%22blupi%22,%22strategy%22:%22Simple%22%7D%5D%7D&_=1718551274937&fg=_void_&i=6)) <br> Open is the first word in the name, because Open Eggbert is open-source. <br> Speedy Eggbert is no more a registred trademark and this is reason, why the second word in the name is "Eggbert"
