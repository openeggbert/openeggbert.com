Free Direct

Free Direct
Website https://freedirect.openeggbert.com
Programming language C++
Based on CNA
Licence GPLv3 or later

Free Direct is a DirectX 3-like wrapper around CNA. It reimplements the DirectX 3 API used by the original Speedy Blupi (Epsitec) game, allowing the decompiled source code of Free Eggbert to run on modern platforms without DirectX.

Role in the stack

SDL 3
  └── CNA  (XNA-like API)
        └── Free Direct  (DirectX 3-like API)
              └── Free Eggbert
