Planet Blupi (Open Eggbert fork)
Website https://planetblupi.openeggbert.com
Based on Planet Blupi (Epsitec)
Used libraries Free API, Free Direct
Programming language C++

This is an Open Eggbert fork of the Planet Blupi game by Epsitec. The original Planet Blupi game uses Windows API and DirectX 3. This fork replaces those dependencies with Open Eggbert's own reimplementations: Free API (Windows API replacement) and Free Direct (DirectX 3 replacement built on CNA and SDL 3).

This makes Planet Blupi runnable on Linux, MacOS, Android and Web without Wine or Windows.
