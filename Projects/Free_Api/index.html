Free API

Free API
Website https://freeapi.openeggbert.com
Programming language C++
Reimplements Subset of Windows API
Licence GPLv3 or later

Free API is a partial reimplementation of the Windows API used by the original Speedy Blupi (Epsitec) game. It allows the decompiled source code of Free Eggbert to compile and run on non-Windows platforms without depending on the actual Windows API or compatibility layers like Wine.

Only the subset of Windows API calls that Speedy Blupi actually uses is reimplemented.
