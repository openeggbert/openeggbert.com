Microsoft Music Producer

Microsoft Music Producer is program, which was used to create automatically music in the MIDI format for the games Speedy Blupi I/II.
Runs also on Linux via Wine.
Many PC games in the 90's used this program.
More information: http://timigi.com/Stuff/Archive/blueribbon/msmp.html (Archived)
A program called "DirectMusic Producer" is basically the sequel to Microsoft Music Producer.
