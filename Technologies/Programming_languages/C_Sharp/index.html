C Sharp

"The correct title of this article is C#. The substitution of the # is due to technical restrictions."

What is C#

  • General-purpose high-level programming language supporting multiple paradigms.
  • Very similar to Java programming language.
  • Invented by Anders Hejlsberg, Scott Wiltamuth, and Peter Golde from Microsoft.
  • First distributed in 2000.
  • Official documentation: learn.microsoft.com

C# Runtimes

  • .NET Framework (now discontinued): The original closed-source runtime and compiler developed by Microsoft.
  • Mono: A free and open-source cross-platform compiler and runtime, started in 2004.
  • .NET Core: Free and open-source runtime from Microsoft, first published in 2016. Later renamed to simply ".NET".

.NET Compact Framework 4.0

The .NET Compact Framework 4.0 (CF) is a lightweight version of the .NET Framework 4.0, designed for resource-constrained devices such as mobile phones and embedded systems (e.g., PDAs, Windows CE, and Windows Phone 7).

1. Supported Platforms and Target Devices

  • .NET Framework 4.0: Full-featured desktop computers and servers.
  • .NET CF 4.0: Devices with limited resources like mobile devices and embedded systems.

2. Size and Optimization

  • CF is significantly smaller and optimized for low memory and storage environments.
  • CF excludes non-essential libraries (e.g., advanced graphics or networking).

3. API and Feature Support

  • CF lacks some modern desktop features such as WPF and full WCF support.
  • Includes basic support for Windows Forms, threading, and ADO.NET in limited form.

4. Garbage Collection

  • CF uses a more memory-efficient garbage collector designed for mobile hardware.

5. Libraries and Class Libraries

  • Only a subset of standard .NET libraries is available.
  • Supports UI, collections, threading, and networking basics.

6. Performance and Optimization for Mobile Devices

  • Optimized for startup speed and resource efficiency on constrained devices.

7. Portability

  • CF is not compatible with full desktop .NET Framework applications.

8. Development Tools

  • Uses Visual Studio with special project types (e.g., Visual Studio 2010).

Main Differences Summary

  • CF is a stripped-down version of the full .NET Framework.
  • Best suited for mobile and embedded devices.
  • Standard .NET Framework offers more features for desktop and server apps.

JSIL

JSIL is a compiler that converts .NET applications and libraries from CIL bytecode into standards-compliant JavaScript, which can run in any modern browser or JavaScript runtime. Unlike other JavaScript cross-compilers, JSIL generates JavaScript that is easy to debug while preserving the original .NET code's behavior and structure. Supporting most .NET-based languages, it works seamlessly with C# and VB.NET, with partial support for F#. The compiler handles nearly all .NET runtime features, including pointers and P/Invoke, and can translate most of the open-source Base Class Library (BCL).

Official website: http://jsil.org/
