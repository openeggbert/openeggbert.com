SDL

How to install SDL 3 on Linux

        git clone https://github.com/libsdl-org/SDL.git
        cd SDL
        mkdir build && cd build
        cmake .. -DSDL3_BUILD_SHARED=ON
        make -j$(nproc)
        sudo make install
