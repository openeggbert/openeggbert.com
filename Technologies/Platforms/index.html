Platforms

Types

Desktop

Desktop is the platform for computing.
Examples of the Desktop platforms are: Windows, Linux, MacOS.

Mobile platform

Examples of the Mobile platform are: Android, iOS, Windows Phone.
Hardware types of mobile platform: smart phone, tablet

Smart phone

Smart phone is a mobile device, the has the features of a traditional mobile phone, but also the advanced computing capabilities.
Usual built-in advanced hardware capabilities: touchscreen, camera, GPS, fast access to the Internet, magnetometer, proximity sensor, barometer, gyroscope, acelerometer, LTE, 5G, 4G, Wi-Fi, Bluetooth.
